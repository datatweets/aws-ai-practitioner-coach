# AIF-C01 Official Blueprint Summary

Verified against the AWS Certified AI Practitioner (AIF-C01) documentation on 2026-09-03.

## Exam structure

- Current blueprint version used by this skill: **1.1** (published 2026-04-30).
- Scored-domain weights: D1 20%, D2 24%, D3 28%, D4 14%, D5 14%.
- The official guide describes four possible question formats: multiple choice, multiple response, ordering, and matching.
- The exam contains 50 scored questions and 15 unscored questions; the passing scaled score is 700 on a 100-1000 scale.
- The certification targets foundational understanding and practical business application, not hands-on implementation of model algorithms or production pipelines.

## Current domain map

### D1 - Fundamentals of AI and ML (20%)
- Basic AI/ML terminology, data types, learning types, inference types, fit, and agentic AI terminology.
- Practical AI use cases and managed AWS AI/ML services.
- AI/ML lifecycle, MLOps concepts, model metrics, and business metrics.

### D2 - Fundamentals of GenAI (24%)
- Tokens, chunking, embeddings, vectors, transformers, FMs, LLMs, multimodal models, and diffusion models.
- FM lifecycle, token economics, context engineering, and agentic AI concepts including MCP, memory, tool use, multi-agent patterns, and orchestration.
- GenAI capabilities/limitations, model-selection factors, business value, and AWS GenAI technologies such as Bedrock, SageMaker AI/JumpStart, Amazon Q, Kiro, Strands Agents, and AgentCore.

### D3 - Applications of Foundation Models (28%)
- FM selection and inference parameters; RAG and vector stores; customization cost tradeoffs; agents.
- Prompt techniques, prompt risks, and prompt management.
- Pre-training, fine-tuning, continued pre-training, instruction tuning, RLHF, and distillation.
- Human/automatic evaluation, ROUGE, BLEU, BERTScore, LLM-as-a-judge, and business/application metrics.

### D4 - Guidelines for Responsible AI (14%)
- Fairness, inclusivity, robustness, safety, veracity, dataset quality, legal risk, bias/variance, and monitoring.
- Transparency, explainability, model/service cards, evaluation, and human-centered design.

### D5 - Security, Compliance, and Governance (14%)
- IAM, encryption, Macie, shared responsibility, AgentCore Identity/Policy, Guardrails, data lineage, access/integrity, prompt injection, output validation, and audit logging.
- Governance services and strategies including Config, Inspector, Artifact, CloudTrail, Trusted Advisor, residency, retention, monitoring, and governance frameworks.

## Authority rule

When the practice PDFs and the current AWS blueprint differ in weighting or scope, use the current AWS blueprint for generated practice and explicitly label any source-specific behavior.
